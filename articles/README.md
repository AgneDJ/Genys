# Atskiri straipsnių failai

Kiekvienas naujas straipsnis turi būti atskiras HTML failas šiame aplanke.

1. Nukopijuokite `_template.html` į tinkamą kategorijos aplanką, pavyzdžiui `naujienos/`.
2. Pervadinkite failą aiškiu vardu, pavyzdžiui `rudens-svente-2026.html`.
3. Pakeiskite straipsnio antraštę, datą ir tekstą.
4. Pridėkite jo `link` įrašą į `data/site-data.json`, kad straipsnis atsirastų pagrindinio puslapio naujienose.
