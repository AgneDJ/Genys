# SF „Genys“ turinio puslapiai

Šiame aplanke yra atskiri, redaguojami svetainės puslapiai.

- `apie-mus/` – vadovės žodis, misija ir tikslai, veikla, klasės.
- `tevams/` – tėvų komitetas, atributika, budėjimai, mokslų kainos, Amazon wishlist.
- `naujienos.html`, `pedagogams.html`, `partneriams.html` – pagrindiniai papildomi puslapiai.

Kiekviename puslapyje pažymėta vieta galutiniam tekstui ir nuorodoms įkelti.
